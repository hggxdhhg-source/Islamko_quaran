# ۞ إسلامكو — ISLAMKO

تطبيق ويب إسلامي حديث ومتكامل (PWA) بتصميم زجاجي عصري وفاخر (Glassmorphism)، يدعم العمل دون اتصال بالإنترنت، ومُهيأ بالكامل للتحويل إلى تطبيق هاتف ذكي.

---

## ✨ المميزات الرئيسية

- **📖 المصحف الشريف الإلكتروني:** قراءة مريحة مع أدوات تكبير/تصغير الخط، البحث في السور، وعرض بيانات الآيات.
- **🎧 مكتبة القراء الصوتية:** استماع وتلاوات لأشهر القراء بمختلف الروايات والمصاحف المرتلة، مع مشغل صوتي عائم مستمر ومشغل كامل للشاشة.
- **📿 المسبحة الإلكترونية الذكية:** عداد تفاعلي بدعم اللمس فائق السرعة، نقرات اهتزازية صوتية (Haptic Feedback)، وأهداف تسبيح قابلة للتخصيص.
- **🤲 موسوعة الأذكار والأدعية والأحاديث:** مجموعة ضخمة وشاملة من الأذكار اليومية والأحاديث الصحيحة من صحيحي البخاري ومسلم.
- **🕌 مواقيت الصلاة واتجاه القبلة:** حساب دقيق للمواقيت حسب موقعك الجغرافي، مع بوصلة ملاحية فاخرة ثلاثية الأبعاد (3D Needle) تشير مباشرةً نحو الكعبة المشرفة ومكة المكرمة.
- **🔔 الإشعارات التلقائية الذكية:** دعم التنبيه بأوقات الصلاة، أذكار الصباح والمساء، والتسبيح والصلاة على النبي.
- **📱 PWA & Offline Support:** يعمل كتطبيق مثبت على الهواتف (iOS و Android) والكمبيوتر بدون إنترنت عبر Service Worker.

---

## 🛠️ التقنيات المستخدمة

- **HTML5** دلالي حديث ونظيف.
- **CSS3 / Glassmorphism:** تصميم عصري فاخر، خطوط عربية أصيلة، دعم كامل للوضع الداكن (Dark Mode) والنهاري (Light Mode)، وتجاوب تام مع كافة الشاشات (بما في ذلك أجهزة iPhone 13, 14, 15, 16).
- **Vanilla JavaScript (ES6+):** أداء فائق وسرعة استجابة بدون أي مكتبات أو أطر عمل ثقيلة.
- **Web Audio API & Service Worker:** لتوفير استجابة حسية وتجربة Offline سلسة.
